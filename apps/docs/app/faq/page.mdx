        <h1 id="faq">FAQ</h1>
        <p className="lede">Five situations worth knowing before you publish.</p>

        <h2 id="configuration">Configuration still fails</h2>
        <p>Run <code>{"syndroo doctor --local"}</code>: it names the failing check and sends nothing. When the failing check is a credential, confirm the exported group is present in this shell and re-register the account as described in <a href="/accounts/">Account configuration</a>. Each named platform has its own credential group and its own binding.</p>

        <h2 id="changed-source">I edited the file after confirming</h2>
        <p>Within one publish, an edit made while or after confirming cannot change what is sent: publishing reads the file once and sends the snapshot it validated. A separate publish after a dry-run reads the current file, so edits between those commands do change its input. Check the receipt before considering any new post; changing a key is not a repair for a failed or unknown result.</p>

        <h2 id="duplicate-key">The same key again</h2>
        <p>A <code>{"key"}</code> is the identity of one post. Repeating a publish with the same key and the same content does not create a second copy, and the same key with different content is refused instead of sent again. A target that already succeeded is never republished.</p>

        <h2 id="unknown-result">The result is unknown</h2>
        <p>An <code>{"unknown"}</code> target may have reached the platform. Read the receipt, inspect the platform account by hand and stop: an unknown target stays blocked, and neither an automatic nor a deliberate retry may resend that content blindly.</p>

        <h2 id="state-recovery">Recover the local state</h2>
        <p>Stop every other Syndroo process first, then inspect and recover:</p>
        <pre data-label="terminal"><code>{"syndroo state inspect\nsyndroo state recover --confirm-no-writers --yes"}</code></pre>
        <p>If the state holds a lock with no readable owner, stop and diagnose it by hand instead of deleting the state directory.</p>
