        <p className="eyebrow">Syndroo docs</p>
        <h1 id="quick-start">Publish text to Bluesky and Threads from your terminal.</h1>
        <p className="lede">The <code>{"syndroo"}</code> command publishes plain text from this machine, in the foreground, with no server in the path. <strong>0.6.0-rc.1 candidate; live-account testing pending.</strong></p>

        <h2 id="install">1. Install</h2>
        <p>Requires Node.js 22 or newer on macOS or Linux. Windows is not supported for local writes.</p>
        <pre data-label="terminal"><code>{"git clone https://github.com/Syndroo/syndroo\ncd syndroo\nnpm ci\nnpm run build\nnpm run pack:cli\nnpm install --global ./artifacts/syndroo-cli-0.6.0-rc.1.tgz\nsyndroo init --namespace default\nsyndroo doctor --local"}</code></pre>

        <h2 id="bind-one-account">2. Bind one account</h2>
        <p>Bluesky uses an app password; keep the variables in the environment the CLI runs in, because they are read again on every execution.</p>
        <pre data-label="terminal"><code>{"export BLUESKY_IDENTIFIER=\"your-handle.bsky.social\"\nexport BLUESKY_PASSWORD=\"app-password\"\nsyndroo auth set bluesky --local --from-env\nsyndroo auth status --local"}</code></pre>
        <p><a href="/accounts/">Account configuration</a> covers Threads and the credential-file option.</p>

        <h2 id="publish">3. Publish</h2>
        <p>Save the document as <code>post.json</code>.</p>
        <pre data-label="post.json"><code>{"{\n  \"schemaVersion\": 1,\n  \"key\": \"first-post-001\",\n  \"content\": \"Syndroo now publishes from the command line.\",\n  \"platforms\": [\"bluesky\"]\n}"}</code></pre>
        <p>The preview writes the plan and sends nothing; its id is <code>{"result.planId"}</code>. Check the text and account in the preview, then replace <code>{"<result.planId>"}</code> with its ID and execute. The execution runs that same plan and reports <code>{"result.operationId"}</code>.</p>
        <pre data-label="terminal"><code>{"syndroo publish --input post.json --dry-run --json\nsyndroo publish --plan <result.planId> --yes --no-input --json"}</code></pre>

        <h2 id="read-the-result">4. Read the result</h2>
        <p>Each target reports its own status, attempts, remote id and url. For an <code>{"unknown"}</code> target, inspect the platform by hand and do not resend.</p>
        <pre data-label="terminal"><code>{"syndroo receipts show <result.operationId> --json"}</code></pre>
