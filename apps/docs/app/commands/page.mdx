        <h2 id="flags">Flags</h2>
        <ul>
          <li><code>{"--json"}</code> writes exactly one object to stdout and sends every diagnostic, including the preview, to stderr.</li>
          <li><code>{"--local"}</code> selects the local path for <code>{"doctor"}</code> and the auth commands.</li>
          <li><code>{"--state-home <path>"}</code> and <code>{"--namespace <name>"}</code> override the state location and deduplication domain for one run.</li>
          <li><code>{"--yes"}</code> confirms without a prompt and <code>{"--no-input"}</code> never prompts; a non-interactive run needs both.</li>
          <li><code>{"--from-env"}</code> or <code>{"--credential-file <path>"}</code> chooses the credential source, and <code>{"--expect-account <id>"}</code> pins the account a non-interactive run verified.</li>
          <li><code>{"--verify"}</code> re-checks an identity over the network without changing the binding.</li>
          <li><code>{"--input <path|->"}</code>, <code>{"--plan <plan-id>"}</code> and <code>{"--to <csv>"}</code> name the document, a frozen plan, and retry targets.</li>
          <li><code>{"--confirm-no-writers"}</code> is the recovery confirmation, <code>{"--limit <n>"}</code> bounds a listing, and <code>{"--timeout <duration>"}</code> bounds an execution or an explicit verification.</li>
        </ul>

        <h2 id="exit-codes">Exit codes</h2>
        <div className="table-wrap">
          <table>
            <thead>
              <tr><th scope="col">Code</th><th scope="col">Meaning</th></tr>
            </thead>
            <tbody>
              <tr><th scope="row"><code>{"0"}</code></th><td>The command finished: a plan was written, a read succeeded, or a run fully succeeded.</td></tr>
              <tr><th scope="row"><code>{"1"}</code></th><td>Local I/O or runtime failure, or a trusted success that could not be persisted.</td></tr>
              <tr><th scope="row"><code>{"2"}</code></th><td>Admission failure: usage, config, document, confirmation or binding. No content request.</td></tr>
              <tr><th scope="row"><code>{"4"}</code></th><td>An unknown write result. Read the receipt before doing anything else.</td></tr>
              <tr><th scope="row"><code>{"5"}</code></th><td>The operator declined before any content request.</td></tr>
              <tr><th scope="row"><code>{"6"}</code></th><td>The run ended without full delivery.</td></tr>
              <tr><th scope="row"><code>{"130"}</code></th><td>The process stopped on a signal. An in-flight write is not cancelled.</td></tr>
            </tbody>
          </table>
        </div>
        <p>The local surface does not return exit <code>{"3"}</code>.</p>

        <h2 id="examples">Short examples</h2>
        <pre data-label="terminal"><code>{"syndroo publish --input post.json --dry-run --json\nsyndroo publish --plan <result.planId> --yes --no-input --json\nsyndroo receipts show <result.operationId> --json\nsyndroo retry <result.operationId> --to threads --dry-run --json"}</code></pre>
        <p>With <code>{"--json"}</code>, stdout carries one envelope: <code>{"{schemaVersion, command, mode, ok, result, error}"}</code>. Read <code>{"result.status"}</code> as well as the exit code, because a preview can be <code>{"ok"}</code> while nothing was published.</p>
