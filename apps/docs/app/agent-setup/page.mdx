        <h1 id="agent-setup">Drive publishing from an agent</h1>
        <p className="lede">The CLI ships the Syndroo Skill, which describes the same two-phase workflow for an agent: preview a plan, check authorization, execute that same plan, and report every target.</p>

        <h2 id="load-the-skill">Load the Skill</h2>
        <p>Install the CLI and bind one account first, using <a href="/">Quick start</a> and <a href="/accounts/">Account configuration</a>. Then point a Skill-capable client at the bundled directory, which holds <code>{"SKILL.md"}</code> and its references:</p>
        <pre data-label="terminal"><code>{"syndroo skill path"}</code></pre>
        <p>Your agent needs permission to run shell commands.</p>

        <h2 id="the-flow">The flow</h2>
        <pre data-label="terminal"><code>{"syndroo doctor --local\nsyndroo auth status --local\n\nsyndroo publish --input post.json --dry-run --json\nsyndroo publish --plan <result.planId> --yes --no-input --json\nsyndroo receipts show <result.operationId> --json"}</code></pre>
        <p><code>{"doctor --local"}</code> and <code>{"auth status --local"}</code> read only; the status command stays offline unless you add <code>{"--verify"}</code>.</p>

        <h2 id="steps">Steps the agent takes</h2>
        <ol className="steps">
          <li>
            <h3 id="read-the-skill">Read the Skill</h3>
            <p>Open the directory <code>{"syndroo skill path"}</code> prints and follow its workflow.</p>
          </li>
          <li>
            <h3 id="request-approval">Request approval of the text and the account</h3>
            <p>Show the preview to the user and continue only when the text and the target account are the ones they approved.</p>
          </li>
          <li>
            <h3 id="execute-and-report">Execute and report</h3>
            <p>Run the approved plan, then report the operation id and one honest outcome per target.</p>
          </li>
        </ol>
        <p>Keep credentials out of prompts and command arguments, and inspect the platform by hand when a target comes back <code>{"unknown"}</code>.</p>
